Multichat help

Your right-side tabs are the real chats. This panel is FAQ only.

Lock this UI

1. Docks → Lock Docks (keeps panels from drifting)

2. Quit OBS once normally so layout saves

3. Layout backup lives in %AppData%\obs-studio\user.ini (+ .bak-layout-loved-*)

Sign-in

YouTube + Twitch: sign in once each via right‑click dock → Interact. Cookies stay in OBS.

Kick: official popout is read-only in OBS (Kick’s rule). Messages show; reply in Kick browser/app.

All chats in one feed + send to all?

Not with these official docks. Tabs = one platform at a time (read/send on that tab).

True merged read + “send to all three” needs a chat aggregator (we avoided Restream/Aitum). Official docks can’t legally/reliably merge + fan-out replies.

Stream to YouTube + Twitch + Kick together

OBS Settings → Stream is always one destination. That’s normal.

Use the Multiple Output dock from obs-multi-rtmp (free plugin) — add 3 Custom RTMP targets. Never paste stream keys in chat.
